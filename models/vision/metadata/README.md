# Vision model metadata

Keep small metadata records here for approved local model artifacts. Do not
store weights, exported engines, cache files, datasets, or training outputs in
this directory.

Each metadata file should record enough information to reproduce or audit the
artifact without committing the artifact itself: source model, local target path,
download URL or internal release reference, license, prompt/class order,
training/evaluation config, dataset hash, checkpoint hash, and acceptance notes.
