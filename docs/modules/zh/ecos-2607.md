# ECOS 中文摘要

ECOS 是 **Embodied Cognition Operating System**，即具身认知操作系统。它是机器人侧运行时，负责把上层 Agent 的工具调用转化为实际的感知、控制、仿真或硬件动作。

完整英文文档见：[../en/ecos-2607.md](../en/ecos-2607.md)。

## 1. 模块定位

ECOS 可以理解为机器人系统的“身体侧”：

```text
GECA / SensorAgent：决定做什么
ECOS：负责怎么安全可靠地执行
```

ECOS 不负责大模型推理或任务规划，而是负责运行时能力：

```text
ROS 2
感知流水线
运动与抓取控制
硬件驱动
Isaac Sim 桥接
状态存储
安全检查
生命周期和心跳
```

## 2. 与 SensorAgent 的关系

SensorAgent 不直接调用 ROS 2 topic、机械臂驱动或仿真接口，而是通过 API / MCP / tool adapter 调用 ECOS 暴露的能力。

例如：

```text
SensorAgent workflow
→ robot.pick tool
→ ECOS skill / runtime
→ ROS 2 / MoveIt2 / 机械臂驱动
```

## 3. ECOS 负责的能力

ECOS 侧通常负责：

```text
capture_rgbd
get_robot_state
move_to
grasp
place
verify_state
emergency_stop
```

这些能力可以被包装为 MCP tools 或 API endpoints，供 SensorAgent 调用。

## 4. 安全边界

物理安全属于 ECOS，而不是 SensorAgent。

例如：

```text
碰撞检测
关节可达性
工作空间边界
力/力矩限制
急停
硬件 watchdog
```

SensorAgent 可以决定“要抓取目标物体”，但 ECOS 必须决定“这个动作是否安全、是否可执行”。

## 5. 对本仓库的意义

本仓库只需要维护 ECOS 的调用契约和 adapter，不需要实现 ECOS 本身。

在 SensorAgent 中，对 ECOS 的依赖应体现为：

```text
tools/robot/
integrations/
schemas/
configs/integrations.yaml
```
