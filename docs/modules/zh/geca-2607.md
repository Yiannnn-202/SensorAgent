# GECA 中文摘要

GECA 是 **General Embodied Cognition Agent**，即通用具身认知智能体。它是整个系统的决策侧，负责理解任务、规划步骤、调用工具，并根据执行反馈调整后续行为。

完整英文文档见：[../en/geca-2607.md](../en/geca-2607.md)。

## 1. 模块定位

GECA 可以理解为机器人系统的“大脑侧”：

```text
GECA：负责想、规划、调用工具
ECOS：负责感知、控制、执行、硬件安全
```

GECA 不直接操作机器人驱动，也不直接依赖具体 ROS 2 topic。它通过 MCP / API 调用运行时能力。

## 2. 与 SensorAgent 的关系

SensorAgent 是 GECA 思想在本项目中的具体实现。

在本仓库中，GECA 侧能力体现为：

```text
agent/
mcp/
skills/
tools/
workflows/
logger/
state/
integrations/
```

## 3. 核心机制

GECA 侧的核心机制包括：

```text
任务理解
状态队列 / 上下文
工具注册表
技能注册表
规划器
ActionList / DecisionTree
执行监视
日志记录
```

## 4. 与外部模块协作

GECA / SensorAgent 通过稳定协议调用外部能力：

```text
MCP
HTTP API
WebSocket
其他 Agent 服务
```

外部模块可以是视觉、音频、机器人运行时、仿真环境或评测服务。

## 5. 对本仓库的意义

SensorAgent 的近期目标就是先把 GECA 侧框架搭好：

```text
tool / skill schema
registry
workflow runtime
structured logger
external adapter
API / CLI entry point
```

等框架稳定后，再针对具体赛题编写 workflow。
